# Automated Road Damage Detection

## Overview
This project is an AI-based road damage detection system that identifies road damages such as potholes and cracks using deep learning and drone images.

## Features
- Detects road damages automatically
- Uses deep learning models
- Supports image-based testing
- Easy to run using Python

## Tech Stack
- Python
- OpenCV
- Deep Learning
- NumPy
- TensorFlow / PyTorch

## Project Structure

```bash
Automated-Road-Damage-Detection/
│
├── Output/
├── testImages/
├── Main.py
├── best.pt
├── requirements.txt
└── run.bat
```

## Installation

```bash
pip install -r requirements.txt
```

## Run Project

```bash
python Main.py
```
